# Tutorials and Examples

Start with the [Quick Start Guide](../quick-start.md), then choose a path:

1. [Runtime Modules and Frames](runtime.md) explains modules, presets, lazy
   evaluation, caching, child Frames, recalculation, limits, and cleanup.
2. [LCL examples](language.md) teaches the expression language from literals
   through comprehensions, arrow functions, closures, control forms, recursion,
   Fibonacci, and quicksort.
3. [Configuration files](configuration.md) builds and loads `.lclcfg` documents,
   composes them with `using`, and evaluates the result.
4. [Dependency analysis](dependency-analysis.md) covers static references,
   Module and Frame graphs, runtime traces, snapshots, and inspection.
5. [Command-line applications](cli.md) builds a typed async CLI with config,
   overrides, dry-run handling, and logging.
6. [Workflow status](workflow.md) records nested task and step outcomes and
   finalizes scopes safely.

For exact contracts, use the [reference index](../reference/README.md).
