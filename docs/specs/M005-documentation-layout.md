# M005: documentation layout

## Contract

English specifications live in `docs/specs`, English user tutorials in
`docs/tutorials`, and Chinese tutorial translations in `doc_cn` with `_cn`
filename suffixes. The root README pair is the bilingual entry point.

Every milestone specification follows the checked-in template and contains a
contract, public interfaces where applicable, failure behaviour, test cases,
and objective acceptance evidence. Tutorial indexes may list planned topics but
must label them as planned rather than implemented.

## Acceptance

- Every documentation directory has an index describing its language and role.
- A reusable milestone-specification template exists.
- Indexes link back to progress and user-facing README documents.
