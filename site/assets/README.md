# lclang logo

`logo.png` is the project logo supplied by the project owner on 2026-09-11.
It is preserved byte-for-byte from the supplied PNG: a blue, navy, and pale-blue
geometric symbol above the lclang wordmark on a light background.

The website, repository README, package description, and documentation Wiki
share this asset. Preserve its square aspect ratio, background, and clear space.
The README uses the absolute Pages URL so its image also resolves on PyPI.

`favicon.png` and `apple-touch-icon.png` are identical copies of the supplied
image. Browsers scale them to their display size. Replace all three files
together when changing the project logo; do not redraw them independently.
