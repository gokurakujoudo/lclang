# lclang logo

`logo.png` is the canonical generated PNG, shared by the website, favicon,
repository README, package description, and documentation Wiki. Keep its square
aspect ratio and transparent margins. License: the repository's MIT license.

`favicon.png` (32 px) and `apple-touch-icon.png` (180 px) are resized copies
of the original, preserving transparency. Regenerate these from the original
when replacing the logo; do not redraw them independently.

Generated with the built-in image-generation tool. The requested model was
`gpt-image-2.5`; the tool does not expose a model selector or identify its model,
so that model attribution is unverified.

## Generation prompt

Use case: logo-brand. Create one final, beautifully designed minimal PNG brand symbol for lclang, the Lazy Context Language, a typed async-first Python configuration language. This is a production logo to use at 32px in website navigation and as a favicon, also enlarged on GitHub README and documentation. A confident geometric lowercase-l / L-shaped rounded white path inside a saturated cobalt-blue rounded square, with one small separate mint circular node in the upper right, suggesting a deferred value and contextual dependency. Carefully balanced negative space, optically balanced proportions, bold simple silhouette, elegant precision. Palette matches existing website: blue #1856d6, white #ffffff, mint #99dec5. Flat solid fills, crisp edges, no gradients, shadows, 3D, textures, mockup scenes, borders, extra ornaments, lettering or wordmark. Center the square mark filling approximately 90% of a square 1024x1024 canvas, with truly transparent outside corners and margins (alpha, no checkerboard painted into the image). Output a single polished symbol, not a presentation sheet or multiple options.
